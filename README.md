# Movies List

A React app for browsing popular movies, searching for movies, and saving favorites in the browser.

## Getting started

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and add your TMDB API key.
3. Start the development server with `npm run dev`.

The TMDB API key is read from `VITE_TMDB_API_KEY`. Do not commit `.env`.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build
